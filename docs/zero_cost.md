# Zero-cost core verification

Mandatory core components use public SEC data and locally runnable open-source models. No OpenAI, Anthropic, Gemini, Pinecone, Bloomberg, FactSet, Capital IQ, AlphaSense, paid SEC aggregator, FRED key or permanent hosted GPU is required.

Optional Docker services run locally. Optional commercial provider keys remain blank/disabled. Public deployment can fall back to a transparent CPU demo plus recorded full local execution if free GPU hosting is unavailable.
